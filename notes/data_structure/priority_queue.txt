【ポイント】
・遅延加算
・操作2の「全要素にXを加える」を毎回やると遅い
・全要素に同じ値を加えても大小関係は変わらない
・加算分をcntとしてまとめて管理する
【解法】
・操作1：X - add をpriority_queueに入れる
・操作2：add += X
・操作3：pqの最小値 + add を出力して削除する
【計算量】
O(Q log Q)
【詰まったところ】
.
【覚えること】
・全要素への同じ加算 → 変数1つで管理
・追加するとき X - add
・取り出すとき pq.top() + add
・priority_queueで最小値を管理する場合はgreaterを使う
